# الإجازة الذهبية للسفر والسياحة | Golden Vacation Landing Page

صفحة هبوط تسويقية فاخرة وعالية التحويل (High-Conversion Luxury Landing Page) لشركة **الإجازة الذهبية للسفر والسياحة** في المملكة العربية السعودية، مصممة خصيصاً لحملات Google Ads وSnapchat Ads.

---

## ✨ أهم المميزات
- **تصميم فاخر مطابق لفكرة فيجما (RTL First)** بهوية بصرية كحلية وذهبية ناعمة.
- **7 باقات سياحية حصرية** لشخصين (كوريا الجنوبية، المالديف، لندن، النرويج، تايلاند، جورجيا، موريشيوس).
- **سحب تفاعلي بالماوس واللمس (Mouse Swipe & Touch Drag)** بدون أزرار فلاتر لتجربة تصفح غامرة.
- **تتبع ذكي لمصادر الحملات الإعلانية:**
  - إضافة تلقائية لكود `{G2}` لإعلانات Google Ads في نهاية رسائل الواتساب.
  - إضافة تلقائية لكود `{S2}` لإعلانات Snapchat Ads في نهاية رسائل الواتساب.
  - دعم رقم دعم الواتساب الرسمي المعتمد: `+966551433434`.
- **تحقق ذكي وصارم من رقم الجوال والاسم** مع مؤشرات خطأ وصحة فورية.
- **ربط مباشر مع Google Sheets** عبر Webhook لتسجيل العملاء المحتملين تلقائياً مع مصدر الحملة.
- **زر واتساب عائم** مع نبض تفاعلي للتواصل السريع.
- **روابط التواصل الاجتماعي الرسمية الأفقية** بالفوتر.
